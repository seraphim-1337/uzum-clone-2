# Uzum Market Clone

Frontend-клон маркетплейса Uzum Market, созданный как дипломный проект.

## Возможности

- Главная страница;
- каталог товаров;
- категории;
- поиск;
- autocomplete-подсказки;
- история поиска;
- фильтры и сортировка;
- страница товара;
- корзина;
- промокод `UZUM10`;
- расчёт доставки;
- checkout;
- оформление заказа;
- история заказов;
- детали заказа;
- статусы заказа;
- избранное;
- недавно просмотренные товары;
- рекомендации;
- профиль/авторизация;
- мобильная навигация;
- responsive-дизайн;
- 404.

## Технологии

- HTML;
- CSS;
- JavaScript (ES-модули);
- Vite — сборка и dev-сервер;
- JSON Server — локальный mock API для данных `db.json`.

## Запуск проекта

### Установка зависимостей

```bash
npm install
```

### Запуск frontend (Vite)

```bash
npm run dev
```

Dev-сервер по умолчанию доступен на `http://localhost:5173`.

### Запуск backend / JSON Server

В отдельном терминале:

```bash
npm run server
```

JSON Server запускается на `http://localhost:3001` и отдаёт данные из `db.json`. Vite перенаправляет запросы `/api/*` к нему. Если сервер не запущен, приложение показывает встроенный демонстрационный каталог-фолбэк и остаётся работоспособным.

### Production build

```bash
npm run build
```

Готовые статические файлы попадут в папку `dist`. Просмотреть сборку локально можно через:

```bash
npm run preview
```

## Структура проекта

- `src/` — исходный код приложения (точка входа `src/main.js`, роутер `src/router.js`, глобальные стили `src/style.css`);
- `src/components/` — переиспользуемые компоненты: шапка, подвал, hero, карточка товара, категории, поиск, слайдер, тосты;
- `src/pages/` — страницы: главная, каталог, товар, корзина, checkout, избранное, профиль, 404;
- `src/services/` — работа с API (`api.js`) и localStorage (`cart.js`, `favorites.js`);
- `src/styles/` — CSS по отдельности для каждой страницы/компонента;
- `src/assets/` — статические изображения, включая иконки категорий;
- `db.json` — данные товаров и категорий для JSON Server.

## Данные

Товары и категории хранятся в файле `db.json` и отдаются JSON Server'ом по адресам `/api/products` и `/api/categories`. Если JSON Server не запущен, используется встроенный демонстрационный каталог, поэтому приложение остаётся работоспособным.

## LocalStorage

Основные ключи localStorage:

- `uzum-cart` — корзина;
- `uzum-favorite` — избранное;
- `uzum-search-history` — история поиска;
- `uzum-recent` — недавно просмотренные товары;
- `uzum-cart-promo` — применённый промокод;
- `uzum-orders` — история заказов;
- `uzum-last-order` — последний оформленный заказ.

## Примечание

Проект предназначен для демонстрационных/дипломных целей: авторизация, корзина и заказы хранятся локально в браузере (localStorage), а `json-server` используется только как локальный mock API.
