# Uzum Market — frontend clone

Адаптивная витрина маркетплейса на HTML, CSS и JavaScript (Vite). Данные о товарах запрашиваются через `json-server`; если сервер не запущен, интерфейс показывает встроенный демонстрационный каталог, поэтому приложение остаётся работоспособным.

## Запуск

```bash
cd uzum-clone
npm install
npm run server
```

В отдельном терминале:


```bash
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию `http://localhost:5173`). API доступен на `http://localhost:3001`, а Vite перенаправляет запросы `/api/*` к нему.

## Сборка для размещения

```bash
npm run build
```

Готовые статические файлы будут в папке `dist`.

## Основные страницы

- `#/` — главная витрина, категории и популярные товары;
- `#/catalog` — каталог, поиск и фильтрация по категории;
- `#/favorites` — избранные товары;
- `#/cart` — изменение количества, удаление позиций и сумма заказа;
- `#/checkout` — форма оформления заказа с HTML-валидацией;
- `#/profile` — вход по номеру телефона с HTML-валидацией.

Корзина и избранное сохранены в `localStorage`, поэтому остаются при перезагрузке страницы. Для реальной авторизации, платежей и заказов понадобится защищённый серверный API — `json-server` используется только как локальный mock.
